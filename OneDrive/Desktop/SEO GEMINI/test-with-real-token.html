Step 3: Test Extension

  3. ใน Console พิมพ์:
chrome.storage.local.set({ 'youtube_auth_token': 'YOUR_TOKEN_HERE' }, () => { console.log('✅ Real token saved!'); location.reload(); });

🎯 Expected Results

หลังจากใส่ real token ใน Extension:

  • ✅ Status แสดง "Authenticated"
  • ✅ "Load My Videos" ทำงานได้
  • ✅ แสดง YouTube videos จริง
  • ✅ สามารถเลือก videos ได้
  • ✅ API calls ทำงานได้จริง

⚠️ หมายเหตุ

  • Token จะหมดอายุใน 1 ชั่วโมง
  • ใช้สำหรับทดสอบเท่านั้น
  • Production ต้องใช้ proper OAuth flow
  • ไม่แชร์ token กับคนอื่น
