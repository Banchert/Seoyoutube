📋 วิธีสร้าง OAuth Client ID:

  1. ไปที่: Google Cloud Console
  2. สร้าง Project ใหม่ (ถ้ายังไม่มี)
  3. Enable YouTube Data API v3
  4. คลิก "+ CREATE CREDENTIALS" → "OAuth client ID"
  5. Application type: Web application
  6. Name: YouTube AI Optimizer (Your Name)
  7. Authorized redirect URIs: https://banchert.github.io/Seoyoutube/
  8. คลิก "CREATE" และคัดลอก Client ID
