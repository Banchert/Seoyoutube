🔧 Setup Your Own OAuth

เพื่อความปลอดภัย ให้คุณสร้าง OAuth Client เอง

Step 1: สร้าง Google Cloud Project

  1. ไปที่: Google Cloud Console
  2. สร้าง Project ใหม่
  3. Enable YouTube Data API v3

Step 2: สร้าง OAuth Client ID

  1. ไปที่: APIs & Services → Credentials
  2. CREATE CREDENTIALS → OAuth client ID
  3. Application type: Web application
  4. Authorized redirect URIs:
https://banchert.github.io/Seoyoutube/

Step 3: ใส่ Client ID ของคุณ

⚠️ สำคัญ: ไม่ต้องใส่ Client Secret เพราะเป็นข้อมูลลับ!

✅ Configuration Saved!
